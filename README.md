# Хомяк 3D 🐹

Браузерная игра на **Three.js r180**: объёмный вольер с вращением камеры, объёмными хомяками и автономным поведением. Пол, прозрачные стенки, домик, колесо, лестница, горка, тоннель, миска и поилка состоят из 3D-геометрии. Хомяки поворачиваются по направлению движения, перебирают лапами, едят, пьют, спят и катаются с горки. Колесо вращается во время бега.

Без регистрации, cookies, localStorage и сохранений. Обновление страницы начинает новую игру.

## Запуск

Нужен современный браузер с WebGL 2 и Node.js 20+ для локального HTTP-сервера:

```sh
npm start
```

Откройте `http://localhost:3000`. Устанавливать зависимости не нужно: Three.js и OrbitControls находятся в `vendor/`, версия зафиксирована, лицензия MIT включена.

Прямое открытие `index.html` через `file://` не подходит: браузер ограничивает загрузку ES-модулей. Используйте локальный сервер или статический хостинг.

## Управление камерой

| Действие | ПК | Телефон |
| --- | --- | --- |
| Повернуть вольер | Перетаскивание левой кнопкой мыши | Перетаскивание одним пальцем |
| Приблизить / отдалить | Колесо мыши или кнопки + / − | Жест двумя пальцами или кнопки + / − |
| Вернуться к общему виду | Кнопка ⌂ | Кнопка ⌂ |
| Выбрать хомяка | Клик по модели, имени или карточке | Нажатие на модель, имя или карточку |

В фокусе 3D-сцены также работают стрелки для вращения, + / − для масштаба и Home для общего вида. Вращение камеры доступно и на паузе. Перетаскивание и масштабирование не выбирают хомяков случайно.

## Уход

- Первые три жильца — Персик, Пиксель и Снежок: рыжий сирийский, серый джунгарский и белый хомяк.
- Кнопки **− / +** меняют число жильцов от 1 до 10. Новые виды чередуются; удаляется последний жилец.
- Выбор хомяка открывает сытость, воду, энергию, настроение, здоровье, занятие, пройденный путь и время в колесе.
- Пополняйте миску и поилку. Малыши идут к ним сами; содержимое в сцене отражает оставшиеся запасы.
- Хомяки обходят мебель, отдыхают в домике, бегают в колесе, поднимаются по лестнице и спускаются с горки. Колесо и горку занимает один хомяк за раз.
- Поглаживания повышают настроение; повтор доступен через 8 игровых секунд.
- Пауза и скорость 1× / 2× / 4× управляют временем. В скрытой вкладке и при открытой инструкции симуляция приостанавливается.

Это условный игровой мир, а не руководство по совместному содержанию реальных животных.

## Размещение

Загрузите файлы на статический хостинг. Для GitHub Pages выберите **Settings → Pages → Deploy from a branch → main → / (root)**. Сборка, ключи и переменные окружения не нужны.

## Структура и проверки

- `scene.js` — WebGLRenderer, OrbitControls, освещение, тени, модели, анимации, Raycaster, управление мышью, клавиатурой и касаниями.
- `navigation.js` — маршрутизация вокруг мебели с точной проверкой пересечения препятствий.
- `engine.js` — потребности, запасы, поведение, занятость оборудования, движение и высота на горке.
- `app.js` — интерфейс и уход; `bootstrap.js` — запуск с обработкой ошибок загрузки/WebGL.
- `vendor/` — Three.js r180, OrbitControls и лицензия MIT; `assets/hamsters.webp` — портреты в карточках, созданные с ImageGen. Плоское изображение вольера удалено.
- `scripts/serve.mjs` — HTTP-сервер без внешних зависимостей.

```sh
npm test
npm run check
```

10 автоматических тестов проверяют потребности и границы населения, паузу и скорость, восстановление, создание объёмных моделей, маршруты вокруг мебели, подъём/спуск по высоте, эксклюзивное использование горки и длительную симуляцию. Тесты геометрии выполняются на CPU; визуальное поведение WebGL в браузерах отдельно не проверялось.

Для шрифта Manrope используется Google Fonts с системным шрифтом в качестве резерва. Three.js, игровая логика и графика загружаются локально с того же хоста.

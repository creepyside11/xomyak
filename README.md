# Хомяк 🐹

Уютная браузерная игра на русском: иллюстрированный вольер, три вида хомяков и забота о каждом малыше. Работает без регистрации, сервера приложения, cookies, localStorage и сохранений. Обновление страницы начинает новую игру.

## Запуск

Откройте `index.html` в современном браузере — установка зависимостей не нужна. Либо запустите локальный сервер с Node.js 20+:

```sh
npm start
```

Адрес: `http://localhost:3000`. Для проверки: `npm test` и `npm run check`.

## Как играть

- Сначала в вольере живут Персик, Пиксель и Снежок: рыжий сирийский, серый джунгарский и белый хомяк.
- Кнопки **− / +** меняют число жильцов от 1 до 10. Добавляются хомяки трёх видов по очереди; удаляется последний жилец.
- Нажмите на хомяка в вольере или в списке: откроются сытость, вода, энергия, настроение, здоровье, текущее занятие, пройденное расстояние и время в колесе.
- Пополняйте общую миску и поилку. Хомяки идут к ним сами. Запасы расходуются во время еды и питья.
- Жильцы гуляют, бегают в колесе, катаются с горки и восстанавливают энергию в домике. Поглаживания поднимают настроение; повторное поглаживание доступно через 8 игровых секунд.
- Доступны пауза и скорость 1× / 2× / 4×. В скрытой вкладке и во время чтения инструкции симуляция приостанавливается.
- При плохом уходе показатели падают, но хомяк не исчезает: корм, вода и отдых помогают восстановиться.

Это условный игровой мир, а не руководство по совместному содержанию реальных животных.

## Структура

`index.html` — интерфейс; `styles.css` — адаптивная вёрстка; `engine.js` — независимая симуляция; `app.js` — взаимодействия; `assets/` — локальные иллюстрации WebP; `tests/` — проверки логики; `scripts/serve.mjs` — сервер без внешних зависимостей.

Иллюстрации созданы для проекта с помощью ImageGen. Внешняя загрузка нужна только для необязательного шрифта Manrope из Google Fonts; при недоступности используется системный шрифт. Игровые файлы и графика локальные.

## Размещение

Содержимое можно загрузить на любой статический хостинг. Для GitHub Pages в настройках репозитория выберите **Pages → Deploy from a branch → main → / (root)**. Игра не требует ключей, переменных окружения или сборки.

## Проверки

Автоматические тесты охватывают границы населения, три вида, безопасное удаление выбранного жильца, паузу и ускорение, кормление и питьё, восстановление энергии, поглаживания, длительную симуляцию при пустых запасах и сброс новой сессии. Адаптивные раскладки рассчитаны на телефон, планшет и ПК; поддерживаются клавиатура и `prefers-reduced-motion`.
